# 数据结构与算法内置课程质量基线

## 1. 定位

《数据结构与算法》是 EduNova 的确定性内置示范课程，不依赖模型、网络或后台任务即可安装。课程包用于：

- 为首次体验提供完整、可引用的课程证据。
- 验证课程空间、RAG、资源、路径、练习和报告闭环。
- 作为后续评估自动建课质量的公开基线。

它不是参考教材的电子化副本。仓库不包含教材 PDF、扫描页、插图、长段原文或教材代码。课程正文、伪代码、问题和 Python 实验均为重新组织的原创表达。

## 2. 内容范围

| 章节 | 知识点数 | 重点范围 |
| --- | ---: | --- |
| 数据结构、抽象数据类型与复杂度 | 5 | 逻辑/存储结构、ADT、时空复杂度 |
| 线性表 | 7 | 顺序表、链表、更新与结构选择 |
| 栈与队列 | 7 | 两类受限线性表、递归与典型应用 |
| 串、数组与广义表 | 6 | BF、KMP、地址映射、矩阵压缩 |
| 树与二叉树 | 8 | 性质、存储、遍历、线索、哈夫曼 |
| 图及图算法 | 8 | 存储、遍历、生成树、最短路、AOE/AOV |
| 查找与散列表 | 7 | 线性/折半查找、BST、AVL、B/B+ 树、散列 |
| 排序 | 8 | 插入、交换、选择、归并、基数与外部排序 |

课程固定包含 9 份内部来源、56 个知识点、184 个证据切片、21 个关键算法 C 风格伪代码和 16 个 Python 实验。

## 3. 自动质量门禁

课程包加载前必须同时通过以下检查：

1. 清单数量、章节顺序、唯一标识和资料引用一致。
2. 先修关系只引用有效知识点、无自引用且构成 DAG。
3. 每个知识点按概念、过程、易错点组织，长度合格且无占位内容。
4. 56 个知识点均有独立学习目标和检查问题；近似度过高会使测试失败。
5. 32 条自然语言问题在无向量模型时也必须通过关键词检索命中预期知识点前三名。
6. 每条检索基准要求对应知识点包含关键事实，防止只靠标题碰巧命中。
7. 16 个 Python 实验必须编译、运行并精确匹配标准输出。
8. 每个实验还必须执行独立边界断言，覆盖空输入、非法位置、溢出、环、负权、不可达、重复关键字和稳定性等风险。
9. 内置来源必须使用 `builtin://`，不得泄露本机路径或在个人资料库创建衍生文件。

标准入口：

```powershell
.\.venv\Scripts\python.exe -m pytest backend\tests\test_builtin_course_seed.py
```

## 4. 质量边界

自动门禁可以证明课程结构一致、代表性事实存在、关键词检索可用、实验标准路径和边界路径可执行，但不能代替专业教师审阅。以下内容仍需在后续版本持续抽查：

- 复杂算法证明和不同教材术语之间的细微差异。
- C 风格伪代码的逐语句可执行性。
- 不同学生画像下资源、练习和路径的真实教学效果。
- 配置外部向量与重排序模型后的语义检索质量。
- 学生完成课程后的真实学习增益。

因此，项目将本课程称为“内置质量基线”或“示范课程”，不宣称它是教材替代品或已经过权威教学认证。
