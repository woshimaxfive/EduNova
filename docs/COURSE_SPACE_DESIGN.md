# EduNova 课程空间设计

## 1. 当前定位

`/app/courses/:courseId` 是学生围绕一门课程持续学习的 AI 对话工作区，也是 A3 个性化学习闭环的课程主场。

课程空间从课程列表裸入口进入时默认展示真实知识图谱；从任务、引用、练习、资源或会话返回时恢复对应正文或对话。画像、检索、弱点、资源、路径、评估和报告仍通过节点详情、回答行动与学习进度按需披露，不堆成首屏说明面板。

```text
课程空间 = 默认知识图谱全景 + 可恢复课程问答 + 节点详情与行动 + 学习进度抽屉
```

登录后首页 `/app` 仍是轻量学习入口，不改成课程驾驶舱。资源工坊、路径、练习和报告继续保留独立页面，课程空间负责在课程上下文中串联这些能力。

## 2. 桌面工作区

桌面端采用固定侧栏和单一主滚动区：

```text
┌──────────────┬─────────────────────────────────────────────┐
│ AppSidebar   │ 返回 课程名 课程状态  问答/课程内容  学习进度 │
│ 课程会话历史 │─────────────────────────────────────────────│
│ 固定不滚动   │                                             │
│              │          当前模式的主要内容                 │
│              │                                             │
│              │─────────────────────────────────────────────│
│              │             固定课程输入框                  │
└──────────────┴─────────────────────────────────────────────┘
```

- 左侧课程历史固定，不随正文滚动。
- 主区域占满剩余视口，垂直滚动条位于浏览器最右侧。
- 课程栏约 60px，固定展示返回、课程名、资料数、知识点数、学习进度和模式切换。
- 问答正文宽度控制在 820 至 900px，长回答保持舒适行长。
- 输入框固定在主区域底部，切换历史后滚动到最新消息。
- 本轮桌面验收宽度为 1440px 和 1920px；移动端沿用现有兼容样式，不作为本轮设计结论。

## 3. 问答模式

问答是默认模式。空会话只显示课程欢迎语、推荐问题和紧邻输入框的课程行动入口，不展示常驻 Hero、八步流程栏或课程状态大面板。

### 3.1 消息呈现

- 用户消息使用右侧深色气泡。
- Assistant 回答使用无卡片 Markdown 正文。
- SSE 临时回答在正文前显示“正在协作回答”、实时用时和真实阶段；完成后收成可展开的“协作完成 · 用时 …”。每条持久化回答均通过自己的 `trace_id` 恢复这组安全步骤，刷新后不得消失；持久化完成前不显示回答工具栏。
- 发送失败时恢复用户输入，不保留半截 Assistant 消息。

### 3.2 逐回答附件

每条持久化 Assistant 回答只突出一个由确定性学习状态规则选出的推荐行动；其余操作始终直接排列在下一行，不使用“更多”折叠：

- 朗读
- 来源
- 生成资源
- 学习路径
- 进入练习
- 学习报告
- 为什么这样回答

学习路径、练习和学习报告在课程空间内使用课程子路由，分别为 `/app/courses/:courseId/path`、`/app/courses/:courseId/practice` 和 `/app/courses/:courseId/reports`。它们固定当前课程、复用该课程的会话侧栏；保留原全局路由作为跨课程工作台入口。

来源必须读取该条消息自己的 `citation_json`，不能统一绑定到最新回答。同一时间只展开一个回答的一种附件，重复点击收起。协作过程收口在回答正文前的状态行：只展示本轮真实 SSE 阶段和耗时，不展示原始思维链、系统提示词或完整模型输入。

推荐优先级固定为待确认弱点、当前路径任务、活跃弱点练习、低掌握知识点、基于引用生成资源、阶段报告。模型不控制导航或任务状态。

从历史回答生成资源时，`learning_goal` 使用该回答前一条用户问题，`knowledge_point_id` 使用该回答最高匹配的有效引用；无有效引用时省略知识点，禁止回退到目录首项。默认选择讲解、思维导图和练习，难度按真实知识点掌握度映射。资源生成继续走 AI 长任务，页面离开或刷新后可从任务托盘恢复。

## 4. 学习进度抽屉

“学习进度”打开右侧覆盖式抽屉，不压缩对话正文。抽屉集中展示：

- 当前目标、证据数量和下一步。
- 画像、检索、辅导、弱点、资源、路径、评估、报告八步状态。
- 待处理弱点和弱点状态流转。
- CourseBuilderGraph 课程生成轨迹。

顶部按钮在有待处理弱点时显示弱点数量，否则显示知识掌握度。知识掌握度对当前课程全部知识点的 `score` 求平均并四舍五入，无知识点时为 `0%`；它与 A3 八步状态是两套不同含义，八步状态不换算成百分比。

打开抽屉会并行强制同步学习状态、掌握度、课程资源、当前路径、最近练习和最新报告。同步期间保留上次成功内容，只显示紧凑状态；部分请求失败时继续保留旧内容并提供局部重试。课程问答、弱点操作、资源生成、路径变更、练习提交和报告生成完成后，相关页面使用统一课程闭环缓存键失效数据，因此当前目标和下一步会随真实状态重新推导。

## 5. 课程内容模式

原“学习模式”改名为“课程内容”。它用于认真学习某个知识点，不再常驻右侧 AI 面板挤压正文。

### 5.1 目录与正文

- 左侧目录按章节分组知识点。
- 存在知识点时默认打开第一个。
- 中间区域可切换“知识点概览”和“知识图谱”。
- 概览通过知识点内容接口展示真实标题、学习目标、课程切片、来源、页码、相关资源和前后知识点导航。
- 图谱复用 `@xyflow/react`，点击节点打开该节点的知识详情抽屉；“继续学习”才进入知识点概览。节点抽屉中的针对练习进入课程内子路由，并在返回时恢复同一节点和抽屉。
- 从回答来源进入时展示该条真实引用片段和检索状态。
- 无关联切片时保留知识点摘要并展示真实空态，不调用模型伪造课程正文。

### 5.2 课程助教悬浮陪学

课程内容中的课程助教默认关闭，通过右下角青绿色按钮打开非模态小面板。面板显示当前课程/知识点、真实掌握度、有效薄弱点、下一行动、最近六条课程消息、快捷草稿、语音输入和最新回答朗读；不使用英文眉题、紫色数字人或自动弹出。

知识图谱和知识点概览均显示助教；完整课程问答不重复显示。进入同课程资源阅读页时携带 `mentor` 与 `course_session_id`，继续同一会话并增加受控当前资源上下文。关闭、`Escape`、切换课程或离开支持页面时停止录音和播放。

## 6. A3 闭环映射

| A3 步骤 | 课程空间表达 |
| --- | --- |
| 画像 | 学习进度抽屉中的画像状态 |
| 检索 | 每条回答自己的真实来源与检索信息 |
| 辅导 | SSE 课程问答与多轮上下文 |
| 弱点 | 进度抽屉中的弱点队列和状态操作 |
| 资源 | 回答后六类资源生成与资源工坊 |
| 路径 | 回答后的路径摘要和独立路径页 |
| 评估 | 带当前 `course_id` 进入练习 |
| 报告 | 带当前 `course_id` 进入报告并查看回流 |

Agent trace 只展示安全协作摘要、节点状态和模型调用汇总，不展示原始思维链、系统提示词、完整模型输入、资料原文或密钥。

## 7. 组件边界

- `CourseSpacePage`：只负责课程空间路由装配。
- `useCourseWorkspaceController`：聚合课程数据、学习进度、回答详情和页面动作，不直接维护会话传输细节。
- `useCourseWorkspaceUrlState`：维护模式、内容视图、图谱范围、知识点详情和回答详情的 URL 可恢复状态。
- `useCourseTutorConversation`：维护课程会话选择、SSE 回答、语音、输入区和持久化消息；图片与文档草稿由 `useCourseTutorAttachments` 独立管理。
- `courseConversation.ts`：会话消息映射、旧回答清理、推荐问题和闭环跳转参数。
- `CourseWorkspaceHeader`：课程栏与模式切换。
- `CourseAssistantTurn`：Assistant Markdown 回合。
- `CourseAnswerDetailPanel`：单条回答的来源、协作轨迹、学习路径和资源入口详情。
- `CourseClosedLoopActions`：逐回答行动栏。
- `CourseInlineResourcePanel`：课程上下文资源生成。
- `CourseProgressDrawer`：A3 进度、弱点和建课轨迹。
- `CourseContentView`：章节目录、知识点概览、图谱和 AI 辅导抽屉。
- `course-space.css`：课程空间专用布局与视觉样式。

失去用途的 `CourseLoopHero`、`CourseStudyStepRail` 和旧 Phase 6.5 课程全局样式已经删除。课程视觉只在 `course-space.css` 维护，`global.css` 不再保留一套重复覆盖层。

## 8. 验收要求

1. 1440px 与 1920px 下侧栏固定，正文滚动条位于浏览器最右侧。
2. 输入框固定在主区域底部，长回答不把输入框推出视口。
3. 空会话首屏只突出课程、推荐问题和输入。
4. 每条 Assistant 回答使用自己的引用和 trace，不串到其他回答。
5. 历史回答生成资源使用对应用户问题。
6. 流式临时回答持久化前没有附件工具栏。
7. 学习进度抽屉覆盖主区且不改变正文宽度。
8. 打开抽屉会绕过缓存陈旧时间同步六组闭环数据，部分失败不清空旧内容且可重试。
9. 课程栏与抽屉使用同一知识掌握度数值，A3 八步不冒充百分比。
10. 弱点操作和 CourseBuilderGraph 轨迹真实可用。
11. 裸课程入口按推荐知识点、活动弱点、最低已评估掌握度和课程顺序选择安全节点，默认展示图谱；明确目标入口恢复概览或聊天。
12. AI 辅导以覆盖抽屉打开，关闭后正文尺寸不变。
13. 无知识点、无引用、无 trace、旧课程和旧资源都有真实空态或兼容降级。
14. 推荐行动、学习进度下一步和跨页入口使用 `/learning/next-action` 的同一课程状态，不给出互相矛盾的建议。
15. 路径、练习和报告可返回原课程 session 与 Assistant 回答；URL 保存课程模式、视图、知识点、图谱范围、章节、详情和回答面板等语义状态，视口只保存在当前标签页。

16. 桌面端图谱提供聚焦链路和课程全景；390px 使用纵向章节链路，状态包含文字且节点可键盘聚焦。
17. 节点详情使用 Radix 右侧抽屉，展示真实掌握度、置信度、证据、弱点、任务和下一行动；产生费用的操作仍跳转既有页面确认。

## 9. 设计结论

课程空间不靠常驻流程图证明赛题能力，而靠每次回答的真实证据、可执行下一步和可恢复的学习状态证明闭环。

## Phase 53 引导式学习与课程完成

由统一下一行动进入知识点时，课程空间展示本次知识点、推荐原因、路径或薄弱证据、可用内容/资源和确定性完成标准。固定顺序为阅读真实内容、按需让课程助教换例子、完成 3 题检查；不显示虚构用时、阅读百分比或自动完成。只有已提交且已评分练习才能形成掌握度证据。

多课程下，课程空间、路径、资源、练习和报告的主动进入会更新该 enrollment 的最近访问时间。课程切换不混用会话、路径、资源或课程画像。归档课程保持只读，可查看全部历史；恢复学习后才重新允许画像、弱点、路径和生成动作。

默认体验应接近成熟 AI 对话产品；深入学习时，再展开 EduNova 特有的课程内容、知识图谱、弱点、资源、路径、评估、报告和多智能体协作证据。

Phase 26 后，空会话的四个同级行动收口为一个“下一步学习”主动作，以及“开始提问 / 自由练习 / 查看报告”次级导航。Assistant 列表只有最新回答显示统一闭环动作，旧回答继续保留与该回答绑定的来源、资源和安全 trace，避免滚动历史出现互相冲突的推荐。
