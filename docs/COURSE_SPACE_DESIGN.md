# EduNova 课程空间 A3 学习闭环设计

日期：2026-07-07

## 1. 文档定位

本文档用于记录 `/app/courses/:courseId` 的 A3 个性化学习闭环设计和当前落地边界。

Phase 6.5 已落地课程空间双模式：默认问答模式承载课程对话，知识点入口收进学习模式，引用来源可以直接进入学习模式。2026-07-07 的 A3 闭环改造在不改变首页定位的前提下，把画像、检索、辅导、弱点、资源、路径、评估、报告和 Agent trace 串到课程空间里，不能回到同一页面堆卡片、堆面板或临时加入口。

一句话方向：

```text
课程空间 = A3 个性化学习闭环主场 + 默认问答模式 + 按需学习模式
```

## 2. 为什么课程空间是主战场

`/app` 首页负责开始学习：提问、上传资料、选择资料、生成课程和回到最近课程。它应该保持像 ChatGPT 一样轻，不承担全部赛题能力展示。

赛题要求的关键能力更适合集中在课程空间里展示：

1. 基于课程资料回答问题。
2. 回答带真实引用和检索状态。
3. 能从知识点、最新问题或弱点上下文生成六类结构化学习资源并直接预览。
4. 能展示多智能体协作证据，而不是只说“用了 Agent”。
5. 能把学习路径、练习评估和报告回流解释成同一条闭环。

因此，课程空间不是普通课程详情页，也不是后台式课程管理页，而是学生围绕某一门课程持续学习的 AI 工作台。

## 3. 两种模式

### 3.1 问答模式

问答模式是课程空间默认状态。

它继承主页的 AI 对话体验，但绑定当前课程上下文：

- 中心区域以课程 AI 对话为主。
- 输入框固定在底部，支持 Enter 发送、Shift+Enter 换行。
- 左侧侧栏显示当前课程自己的历史，不混入主页历史。
- 顶部只保留轻量课程名、资料数、知识点数和必要状态。
- 问答首屏只保留一个轻量知识点入口，不常驻横向知识点滚动条。
- 没有消息时显示推荐问题和开始提问引导，不伪装成固定 AI 回答。
- 有消息时只显示真实课程消息、真实引用和真实检索状态。
- 同一课程 session 内连续追问会带入最近 12 条安全历史；RAG 查询使用最近用户问题 + 当前问题处理“这个”“继续”等指代，但界面只显示上下文计数，不暴露历史全文。

回答下方采用渐进展开：

| 按钮 | 默认状态 | 展开后显示 |
| --- | --- | --- |
| 来源 | 折叠 | 资料名、章节、片段、分数、检索方式 |
| 生成资源 | 折叠 | 选择讲解、思维导图、练习、代码实操、PPT、动画图解，生成后内联查看，也可进入资源工坊管理 |
| 学习路径 | 折叠 | 显示当前课程路径摘要，并可进入真实路径页 |
| 练习与报告 | 折叠 | 带当前 `course_id` 进入练习和报告页，把评估结果回流到课程空间 |
| 课堂协作轨迹 | 折叠 | 展示 Profile、Retriever、Tutor、Weakness、Review、NextAction 的真实 Agent trace、上下文参考计数或空状态 |

问答模式要保持克制：默认不常驻右侧大面板，不把知识图谱、资源队列和 Agent 轨迹全部铺开。

### 3.2 学习模式

学习模式由用户主动进入，不作为默认首屏。

触发入口包括：

- 在问答模式点击知识点入口，再选择某个知识点。
- 点击某条引用来源。
- 打开某个已生成资源。
- 点击学习路径里的下一步任务。
- 从练习或报告回到某个薄弱点。

学习模式的布局：

```text
左侧：课程历史和导航
中间：知识点、资料片段、资源内容、路径任务或练习内容
右侧：当前上下文的 AI 辅导栏
```

右侧 AI 辅导不是客服，也不是新的独立聊天系统，而是当前学习内容的辅助入口。它应该支持：

- 解释当前段落。
- 换一种说法。
- 举例。
- 出一道练习。
- 生成对应资源。
- 把当前内容加入复习路径。

Phase 15 后，中间课程内容区包含真实 `CourseKnowledgeGraph`：使用 React Flow 展示知识点、先修边和掌握状态，点击节点沿用现有知识点学习入口。旧 CSS 绝对定位画布已删除；图谱在 390px 下保持容器内缩放，不制造页面横向滚动。

学习模式适合“认真学某一块内容”，问答模式适合“快速问、连续追问、复习和探索”。

## 4. A3 闭环表达

课程空间顶部不是普通课程详情卡，而是 A3 闭环摘要：

- 当前目标：优先来自最新问题、弱点复习队列、学习路径或课程目标。
- 当前依据：显示资料引用、待处理弱点、已生成资源、学习路径和最新报告是否可用。
- 下一步动作：根据真实状态给出生成资源、继续路径、进入练习、查看报告或先提问的下一步。
- 学习步骤流：固定展示画像、检索、辅导、弱点、资源、路径、评估、报告，状态来自现有课程数据，不伪装闭环已完成。

这层设计借鉴“课堂过程感”，但不做虚拟教室，也不把 OpenMAIC 的互动课堂照搬进来。它的作用是让评审一眼看懂：EduNova 不是聊天页，而是围绕 A3 赛题组织学生学习证据和下一步行动。

## 5. 模式切换规则

模式切换必须轻，不打断学习流：

- 从问答模式点知识点、来源、资源或路径任务进入学习模式。
- 问答模式不直接铺开知识点列表；知识点列表只在学习模式中作为 picker 出现。
- 学习模式可以一键回到问答模式。
- 同一课程内保留当前 active session，不因为切换模式重复创建课程历史。
- 切换模式不弹出中间横向提示条，依靠页面结构、选中态和标题变化表达。
- 切换失败、保存失败、生成失败才使用局部错误或轻量 toast。

## 6. 与现有路由的关系

| 路由 | 角色 |
| --- | --- |
| `/app` | 总 AI 学习主页，不默认绑定课程 |
| `/app/library` | 独立资料库和从资料生成课程入口 |
| `/app/courses/:courseId` | A3 个性化学习闭环主场，承载课程问答、学习模式、闭环摘要和行动入口 |
| `/app/studio` | 全局资源工坊，可查看跨课程资源；课程内生成入口仍优先出现在课程空间 |
| `/app/profile` | 画像查看与证据页；课程空间只展示闭环所需的画像步骤状态 |
| `/app/practice` | 练习入口；课程内练习应能回到对应课程和知识点 |
| `/app/reports` | 报告入口；报告证据应能跳回课程空间 |

`/app/courses/:courseId` 不再只是“课程详情 + 对话”，而是课程上下文的学习主场。
AI 辅导不再设置独立中转页；课程行动区的“开始提问”直接聚焦当前课程输入框。旧 `/app/tutor` 仅作为兼容地址回到学习主页。

## 7. 视觉方向

课程空间应延续主页的高级、干净、AI 原生气质，但比主页更有学习深度。

参考取舍：

- 借鉴 ChatGPT 的对话主导和输入习惯。
- 借鉴 NotebookLM 的资料来源和引用处理。
- 借鉴 Notion 的内容组织和知识块层级。
- 借鉴 Apple 的克制材质、动效和留白。

明确避免：

- 后台管理系统式三栏常驻面板。
- 满屏卡片墙。
- 把 Agent、路径、画像、报告做成后台驾驶舱式大面板。
- 强装饰性的紫蓝渐变、光球和粒子背景。
- 为了说明功能而写大量页面解释文案。

课程空间的视觉记忆点应该是：

```text
学生围绕课程对话，资料证据、资源生成和学习路径从回答下方自然展开。
```

## 8. 数据和接口映射

当前已具备的真实接口可以支撑问答模式：

- `GET /api/v1/courses/{course_id}`
- `GET /api/v1/courses/{course_id}/overview`
- `GET /api/v1/courses/{course_id}/knowledge-points`
- `GET /api/v1/tutor/sessions?scope=course&course_id=...`
- `GET /api/v1/tutor/sessions/{session_id}`
- `POST /api/v1/tutor/sessions/{session_id}/messages/stream`
- `POST /api/v1/rag/search`

Phase 6.5 学习模式已接入：

- 从问答模式点击知识点入口进入学习模式，并在学习模式中选择知识点。
- 点击引用来源直接进入学习模式。
- 学习模式右侧复用当前课程输入能力，不创建第二套 tutor 路由。

课程空间 A3 闭环已复用现有接口接入：

- `GET /api/v1/resources?course_id=...`
- `POST /api/v1/resources/generate`
- `GET /api/v1/paths/current?course_id=...`
- `GET /api/v1/reports/latest?course_id=...`
- `GET /api/v1/agents/traces/{trace_id}`
- `/app/practice?course_id=...`
- `/app/reports?course_id=...`

原则：

- 已有真实数据就用真实数据。
- 没有真实数据就显示空状态、禁用态或预备入口。
- 不用 demo 课程、demo 引用、demo 资源伪装真实能力。

## 9. 状态和提示规则

课程空间不再使用无意义的中间横向提示条。

保留提示的场景：

- 发送失败。
- 模型不可用。
- 资料依据不足。
- 课程生成或资源生成失败。
- 设置保存、测试、删除这类跨页面操作完成。

不保留提示的场景：

- 切换历史。
- 切换知识点。
- 打开或关闭来源。
- 切换搜索、思考等按钮状态。
- 进入某个模式。

这些行为应通过选中态、页面结构变化、抽屉展开和局部内容变化表达。

## 11. 验收标准

后续实现课程空间改造时，至少验证：

1. 默认进入课程是问答模式，不是后台面板。
2. 无消息时只有推荐问题和开始提问引导，不出现固定 AI 示例回答。
3. 有消息时只显示真实消息、真实引用和真实检索状态。
4. 连续追问沿用同一课程 session，上下文化检索能理解最近用户问题。
5. 课程历史和主页历史严格分开。
6. 点击知识点入口或引用可以进入学习模式，知识点选择在学习模式内完成。
7. 学习模式中间显示学习内容，右侧 AI 辅导不抢主位。
8. 来源、资源、路径和课堂协作轨迹默认折叠，展开后不遮挡输入区。
9. 桌面和 390px 移动宽度无水平溢出。
10. 输入区不遮挡最后一条消息。
11. 没有真实能力时不展示假资源、假 Agent 和假报告。
12. 课程空间显示 A3 个性化学习闭环，但 `/app` 首页不被改成驾驶舱。
13. 课程内资源生成可以选择六类资源并内联预览，资源工坊保留为成果库和导出管理页。

## 12. 当前结论

课程空间双模式第一版和 A3 学习闭环第一版已经落地，但这不是终点。

最终方向是：

```text
默认像课程版 ChatGPT，深入时变成可解释的 A3 个性化学习闭环。
```

这能同时满足日常使用、赛题展示和后续多智能体体验打磨。
