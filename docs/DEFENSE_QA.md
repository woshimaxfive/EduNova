# EduNova 答辩问答

更新时间：2026-07-05

## 1. 项目定位

**Q：EduNova 解决什么问题？**

A：EduNova 面向高校学生，把资料建课、课程问答、个性化资源、学习路径、练习评估、报告和导出串成一个可解释学习闭环。它不是单纯聊天助手，而是围绕课程证据和学习状态持续沉淀。

**Q：和普通大模型问答有什么区别？**

A：普通问答通常只回答当前问题。EduNova 会把资料切片、引用、画像、弱点、路径、练习和报告连接起来，并用 Agent trace、引用摘要和质量分说明结果依据。

## 2. RAG 与防幻觉

**Q：如何减少幻觉？**

A：课程空间优先在当前用户课程资料中检索引用。回答、资源、报告和导出都只能使用安全摘要和证据引用。资料不足时显示依据不足或低依据状态，不伪造引用。

**Q：没有 embedding 服务怎么办？**

A：系统支持 OpenAI-compatible embeddings。未配置或不可用时使用显式标记的 `local-hash-1536` fallback，并在前端说明它不是外部语义向量。

## 3. 多智能体

**Q：多智能体是否只是概念？**

A：当前已实现 Agent trace 查询和资源生成六步日志。资源生成会记录 `profile -> retrieve -> diagnosis -> resource -> review -> persist`，但 LangGraph 仍是可观测骨架，不夸大为所有流程的成熟生产编排。

**Q：为什么不用模型直接生成全部内容？**

A：比赛演示和开源部署需要稳定可复现。EduNova 采用确定性可用稿优先，模型只做增强；弱模型、无模型或模型失败时仍能生成可读、可练、可复用的资源。

## 4. 学习画像和弱点

**Q：每门课都有一份画像吗？**

A：没有。用户级长期画像只有一份，保存专业背景、学习目标、认知风格等稳定信息。课程差异通过课程级学习状态、弱点队列、掌握度、路径和资料证据表达。

**Q：课程问答里的弱点会自动确诊吗？**

A：不会。课程问答只生成 `pending` 候选复习项。学生确认后才进入 `confirmed` 或 `reviewing`，学习路径也只消费已确认或复习中的弱点。

## 5. 练习和报告

**Q：练习批改是否依赖大模型？**

A：第一版确定性优先。客观题按标准答案批改，简答题按关键词、课程引用覆盖和关键概念命中率评分。后续可接模型增强，但不能破坏可解释规则。

**Q：报告从哪里来？**

A：报告聚合课程、练习结果、掌握度、弱点队列和下一步建议。Phase 12.1 已支持导出课程级 Markdown 学习档案。

## 6. 部署和开源

**Q：如何一键部署？**

A：使用 Docker Compose 启动 PostgreSQL、Redis、backend、frontend 和 Nginx，统一入口默认是 `http://127.0.0.1:8080`。

**Q：开源时如何处理密钥？**

A：仓库只提交 `.env.example`，真实 `.env` 被忽略。用户 API Key 加密保存，日志、trace、报告和导出不能包含明文 Key。

## 7. 演示模式

**Q：为什么不做共享 demo 账号 reset？**

A：当前快速演示走注册页“带一个示例课程开始”。这种方式能保证每个评审或试用者都有自己的隔离数据，不会共享可写学习记录。独立 demo reset 后续可作为增强，不是当前主线。

## 8. 当前限制

**Q：现在最主要的限制是什么？**

A：PDF/PPTX/DOCX 深度解析、OCR、PDF/Word 导出、异步任务队列、资料对比结果联动期末冲刺、错题驱动深度薄弱点追溯还没有做。当前版本是可运行学习闭环，不是完整商业产品。

**Q：下一步怎么打磨？**

A：Phase 13 继续做 Verification and Hardening：补浏览器 E2E、修验收中发现的断点、提升资源和练习质量、打磨移动端体验，并逐步补深度解析和导出增强。
