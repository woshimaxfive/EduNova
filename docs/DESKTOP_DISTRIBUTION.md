# Windows 桌面分发说明

## 安装与数据

目标平台为 Windows x64。安装包是否可下载及版本信息以仓库 Releases 页面实际附件为准。

安装器采用当前用户安装，创建桌面和开始菜单快捷方式。首次运行会初始化本地服务与数据。用户数据位于 Windows 的 AppData 目录下（通常为 `%APPDATA%/EduNova`），卸载默认保留账号、学习记录和个人设置。备份和迁移时应保护数据库、上传资料与密钥，不要将其上传到问题反馈。

主模型服务需在应用中配置，网络请求和费用由所选服务决定。中文朗读依赖系统中文声音。

## 第三方材料

分发包应携带组件许可证、版权通知、模型来源和适用的对应源码材料。详见 [第三方声明](../THIRD_PARTY_NOTICES.md) 和 [依赖许可](DEPENDENCY_LICENSES.md)。具体模型的许可由随包固定版本材料确定，不能只依据推理运行时的许可证推断。

## 下载与验证

下载后核对发布附件提供的 SHA-256。文件名、版本号或本机构建成功不能代替来源和完整性核对。签名状态、平台兼容性及已知限制见对应版本的 [发布说明](RELEASE_NOTES_0.1.0.md)。

## 源码构建

构建命令和运行配置见 [桌面 README](../desktop/README.md)，运行时接口见 [桌面运行时](DESKTOP_RUNTIME.md)，分发检查要求见 [发布清单](RELEASE_CHECKLIST.md)。
