# EduNova 隐私说明

EduNova 的聊天、课程、资料、学习画像和派生记忆均按登录账号隔离。模型密钥加密保存，接口和页面只返回脱敏摘要；日志、通用 trace 和 Agent trace 不记录完整密钥、JWT、系统提示词、课程原文、画像原文或 Provider 原始响应。

## 跨会话记忆

跨会话记忆默认开启，用于在新会话中找回同一账号过去讨论过的相关学习背景。系统不会复制聊天正文到记忆表，只保存：

- 原会话与用户/助手消息 ID；
- 受长度限制且经过邮箱、手机号和常见密钥模式处理的派生摘要；
- Embedding、模型/Provider、维度和配置指纹。

检索只发生在当前登录用户范围内，排除当前会话且最多返回 5 条。历史对话只帮助理解上下文，不作为教材引用、画像可信证据、弱点、掌握度或练习评分依据。

用户可在“设置 -> 数据隐私”关闭跨会话记忆或清除派生记忆。暂停后停止新的记忆读取和后台写入，保留已有内容与索引；清除派生索引和永久删除记忆是独立操作。原始聊天记录仍保留，便于用户继续查看会话历史。删除聊天或账号时，相关派生记忆按数据库外键级联删除。

管理员可选开启默认关闭的记忆语义筛选实验。开启后，最多5条同账号候选摘要会发送到该账号有效的对话模型进行一次相关性判断；即使最终未选中，候选也已经发送。关闭实验则保持原阈值检索。系统在向量计算后、筛选发送前和返回后复核隐私版本；期间暂停、纠正、删除或清空会丢弃过期结果，先前读取的长期信息也不会继续进入本次摘要。已经发出的模型请求与数据无法撤回；正在执行的同步调用不能保证立即中断，取消检查会在调用边界阻止继续回答。

## 联网搜索

联网只发送完成语义改写后的必要问题文本。系统不会把课程原文、画像、跨会话摘要、历史私聊、JWT 或密钥发送给搜索工具。厂商原生搜索或外部搜索只有返回可验证 URL 时才进入来源面板；搜索结果在课程空间始终标为“外部补充”。

## 下一步学习

统一“下一步学习”只在本地业务数据库中读取当前账号的资料、课程、弱点、路径、练习和报告状态，不调用模型、不发送联网请求，也不保存新的行为事件。接口返回安全 ID 和简短说明，页面跳转与实际写操作仍需要用户确认。
