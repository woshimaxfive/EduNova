# EduNova 隐私说明

聊天、课程、资料、画像与派生记忆按账号隔离。模型密钥加密保存，页面与接口只返回脱敏信息；日志及 Trace 不记录完整密钥、JWT、系统提示词、课程/画像原文或 Provider 原始响应。

## 跨会话记忆

跨会话记忆默认开启，用于找回同账号的学习背景，不复制完整聊天正文，保存：

- 原会话与用户/助手消息 ID；
- 受长度限制且经过邮箱、手机号和常见密钥模式处理的派生摘要；
- Embedding、模型/Provider、维度和配置指纹；
- 用户在设置页明确确认的学习目标、偏好、困难与习惯。

历史片段检索排除当前会话，最多返回 5 条。记忆只提供上下文，不作为教材引用、画像可信证据、弱点、掌握度或评分依据。

“设置 -> 数据隐私”提供独立操作：暂停读取与后台写入、保留内容和索引；清除派生索引、保留摘要；永久删除记忆、阻断旧来源恢复。原始聊天均保留。删除聊天或账号时，相关派生记忆按外键级联删除。

语义筛选默认开启，管理员可关闭并沿用原阈值检索。满足调用条件时，最多 5 条候选摘要发送给有效对话模型作一次相关性判断，未选中的候选也已发送。

系统在向量计算后、筛选发送前和返回后复核隐私版本；期间暂停、纠正、删除或清空会使结果及已读取的长期信息失效。已发送的数据无法撤回，同步调用不保证立即中断，取消在调用边界阻止继续回答。

## 联网搜索

搜索只发送语义改写后的必要问题，不发送课程原文、画像、记忆摘要、历史私聊、JWT 或密钥。厂商原生或外部搜索须返回可验证 URL 才进入来源面板，在课程空间标为“外部补充”。

## 下一步学习

“下一步学习”只读取本地数据库中当前账号的资料、课程、弱点、路径、练习与报告状态，不调用模型、联网或写入新行为事件。接口返回安全 ID 与简短说明，跳转及写操作由用户确认。
