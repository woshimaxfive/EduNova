# EduNova RAG 设计

EduNova 的 RAG 服务于课程学习证据，不是通用网页问答。检索结果必须同时满足用户权限、课程范围和引用可追溯性。

## 1. 数据流

```text
上传资料
→ 文件安全检查
→ 结构提取与目录确认
→ 章节切片
→ 关键词与可选向量索引
→ 课程范围检索
→ 可选重排序
→ 引用绑定
→ 回答与质量审核
```

只有解析质量通过并由用户确认的资料才能进入正式建课和课程检索。

## 2. 召回

检索支持：

- 关键词匹配；
- pgvector 向量候选；
- 关键词与向量结果融合；
- 可选外部 Rerank。

Embedding 或 Rerank 不可用时退回仍然可验证的检索路径。响应中的 `retrieval_source`、`embedding_status` 和 `rerank_status` 反映实际执行方式。

## 3. 用户与课程隔离

检索前必须确认：

- 当前用户可以访问课程；
- 资料和切片属于该课程；
- 结果不跨用户或跨课程；
- 查询中的资源上下文属于当前用户。

向量索引、缓存和重排序同样携带用户与课程范围，不能只在最终返回时过滤。

## 4. 引用

课程引用可以包含：

- 资料或课程来源 ID；
- 标题与章节；
- 页码；
- 短摘录；
- 检索方式和分数；
- Embedding 与 Rerank 状态。

回答中的事实应能映射到返回引用。没有足够课程证据时，系统应提示依据不足，而不是生成看似有来源的引用。

## 5. 网页补充

网页检索用于时效信息、明确核实请求和课程资料之外的补充。网页来源：

- 与课程来源分开标记；
- 必须包含可验证 URL；
- 不直接进入课程知识库；
- 不修改客观评分、掌握度或正式弱点；
- Provider 不可用时返回明确 warning。

## 6. 对话历史

跨会话记忆只在用户启用时提供受限摘要。历史内容不能覆盖当前课程证据，也不能把其他课程的目标、困难或反馈带入当前课程。

## 7. 文档解析

Docling 负责 PDF、DOCX 和 PPTX 的通用结构提取。EduNova 继续负责：

- 目录确认；
- 页码和章节关系；
- 解析质量门禁；
- 章节内切片；
- 配置指纹；
- 用户与课程隔离；
- 引用和检索合同。

扫描件和图片需要单独的 OCR 能力；未启用时不会被标记为已完成文本解析。

## 8. 质量检查

固定评测至少覆盖：

- 预期切片能否进入候选；
- 引用 ID 是否属于允许集合；
- 页码和章节是否一致；
- 无证据问题是否安全拒答；
- Embedding/Rerank 失败是否正确降级；
- 网页来源是否与课程证据隔离；
- 不同用户和课程是否完全隔离。

离线评测不能替代真实 Provider 的延迟、容量和可用性测试。
