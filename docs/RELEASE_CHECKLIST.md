# 发布检查清单

本清单定义每个版本的检查要求。具体执行结果应记录在发布系统或本地维护记录中。

## 源码与构建

- 确认版本、源码提交和构建输入一致。
- 执行适用的自动化检查，核对构建结果。
- 排除本地配置、凭据、用户数据、开发过程记录和临时产物。
- 核对随包依赖、模型、许可证、版权通知及对应源码材料。
- 校验资源清单、文件大小和摘要；分发材料核对完成后才允许正式打包。

## 安装与运行

- 核对安装、首次启动、核心功能、重启和服务退出行为。
- 核对卸载和重装时的用户数据保留行为。
- 检查目标 Windows 环境兼容性、麦克风、中文朗读和保存对话框。
- 在发布说明中明确未验证范围、已知问题和签名状态；不得将未执行的测试写成通过。

## 发布附件

- 核对安装器、SHA-256、版本说明和所需第三方材料。
- 如签名或重新构建，重新计算摘要并检查最终文件。
- 上传后回读目标提交、附件名称、大小与摘要。
- 分别确认草稿和发布状态；草稿存在不代表安装包已可下载。
