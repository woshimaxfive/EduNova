# EduNova 0.1.0 Windows 桌面版

本说明对应 [0.1.0 安装包](https://github.com/woshimaxfive/EduNova/releases/tag/v0.1.0-desktop-source-preview)，源码目标提交为 `75cadabb`。当前分支后续修改不自动包含在已发布安装包中。

## 版本变化

- 提供 Windows 桌面入口、本地服务管理和首次启动初始化。
- 支持当前用户安装，卸载默认保留用户数据。
- 修复 Word 无编号标题解析以及 Windows 中文路径下的 PDF 处理。
- 加强桌面权限、导航、导出和代码验证限制。
- 更新运行依赖，固定 2024 SenseVoice 模型，提供适用的许可证、通知和对应源码材料。

## 使用条件

适用 Windows x64，无需 Docker。主模型在应用内配置，请求与费用取决于所选服务；中文朗读依赖系统中文声音。

数据通常位于 `%APPDATA%/EduNova`。卸载默认保留账号、学习记录和个人设置。安装说明见 [桌面分发说明](DESKTOP_DISTRIBUTION.md)。

## 已知限制

- 独立干净 Windows 环境兼容性尚未验证。
- 真实麦克风、中文朗读听感和人工保存对话框尚未完成验证。
- 安装器尚未提供可信 Authenticode 签名。
- 桌面沙箱和代码策略不构成完整操作系统级隔离保证。
- 可选网络评测依赖的安全限制见 [安全说明](RELEASE_SECURITY_20260927.md)；该依赖不包含在桌面安装包中。
- 未完成全面的真实模型质量与并发性能验证。

## 下载与反馈

安装器与摘要见 Releases。反馈需提供版本、系统信息、复现步骤及脱敏日志，勿提交 API Key、数据库或完整学习资料。
