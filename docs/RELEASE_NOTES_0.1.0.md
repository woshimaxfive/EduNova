# EduNova 0.1.0 桌面源码预览草稿

本版本是 Windows 桌面源码候选。当前草稿不附带 EXE；现有 LocalTest 安装器保留在本地，第三方分发审查和独立干净系统验收尚未完成。仓库可见性保持不变。

## 本版变化

- 增加 Electron Windows 宿主、独立前端托管、首次启动初始化和后台服务生命周期管理。
- 增加安装资源白名单、逐文件哈希检查、第三方分发门禁与 NSIS 当前用户安装入口；卸载保留用户数据。
- 修复 Word 无编号显式标题被 PDF 标题规则丢弃的问题；Windows 中文运行时路径复用 Docling 的 PDFium 后端。
- 限制桌面 IPC、导航、麦克风和导出权限；代码验证器拒绝通过别名引用受限内置函数。
- 增加 Windows 生命周期 CI、桌面打包与权限回归，更新依赖许可索引。
- 将开发测试依赖 httpx2 更新到 2.12.0，并固定共享运行时 AnyIO 4.14.2，修复已公告的安全问题；隔离单元测试的审计数据库写入。

## 使用条件与数据

目标平台为 Windows x64。当前只有开发机实际安装证据，不能视为所有 Windows 版本兼容性保证。中文朗读依赖系统中文声音。主模型由用户自行在应用内配置外部服务；调用会按所选服务处理相关学习内容，服务费用由使用者承担。

用户数据位于 `%APPDATA%/EduNova`（Windows 可将此目录重定向）；卸载默认保留账号、学习记录和个人设置。不要把用户数据目录或 API Key 上传到问题反馈。源码启动、运行资源和打包入口见 [桌面 README](../desktop/README.md)。当前组装器复用已验证本地运行时，不宣称全新机器可一键复现全部二进制构建。

## 验证范围

本轮前端 324 项测试、桌面 13 项测试、真实 Pyodide 策略 11 项测试、离线质量 10 项用例通过；前端构建、ESLint、OpenAPI、Ruff、编码、迁移 head 和 Compose 配置检查通过。后端完整 913 项在安全依赖更新后重跑，结果与远端 CI 链接在创建草稿时附入。

已有 DOCX 修复版 LocalTest 完成真实安装、44,381 个载荷文件核对、空数据启动、重启及卸载数据保留；实际安装版建课、练习反馈、课程对话、PDF/DOCX 导出通过。这些是已有本机安装器证据，不能转用于尚未生成的正式分发包。

## 已知限制

- 当前没有通过第三方分发审查的安装器附件。SenseVoice 转换权重许可链与 Sherpa 原生组件对应源码/分发材料仍有缺项，详见 [分发记录](DESKTOP_DISTRIBUTION.md)。
- 干净 Windows、真实麦克风、中文朗读听感和人工保存对话框未验收；用户本轮确认暂不具备条件。
- 当前 LocalTest 未包含本轮 AnyIO 安全更新，且搜索运行时仍含旧 pip；需更新运行时后重建、重新验收才可作为新的安装候选。当前 LocalTest 未签名。签名不是 GitHub 预发布统一硬门槛，但签名后的文件仍需重新校验和验收。
- Electron sandbox 和代码策略检查不代表完整操作系统级恶意代码隔离验证。
- 可选 Ragas 0.4.3 评测依赖存在已知 SSRF 公告；当前安装包不含此包，业务运行代码未调用该多模态评测功能。不应在不可信资料上启用此可选依赖，待上游修复后复评。详见 [安全检查记录](RELEASE_SECURITY_20260927.md)。
- `release_readiness` 的离线质量用例通过不等于真实模型质量及冷/热、并发性能验收；仍保留 `evidence_gap`，不能宣称完整生产就绪。
