# EduNova 0.1.0 Windows 桌面版

## 版本变化

- 提供 Windows 桌面入口、本地服务管理和首次启动初始化。
- 支持当前用户安装，卸载默认保留用户数据。
- 修复 Word 无编号标题解析以及 Windows 中文路径下的 PDF 处理。
- 加强桌面权限、导航、导出和代码验证限制。
- 更新运行依赖，使用固定版本的 2024 SenseVoice 模型，并提供适用的许可证、通知和对应源码材料。

## 使用条件

目标平台为 Windows x64。主模型服务需在应用中自行配置；相关请求和费用由所选服务决定。中文朗读依赖系统中文声音。

数据通常位于 `%APPDATA%/EduNova`。卸载默认保留账号、学习记录和个人设置。安装说明见 [桌面分发说明](DESKTOP_DISTRIBUTION.md)。

## 已知限制

- 独立干净 Windows 环境兼容性尚未验证。
- 真实麦克风、中文朗读听感和人工保存对话框尚未完成验证。
- 安装器尚未提供可信 Authenticode 签名。
- 桌面沙箱和代码策略不构成完整操作系统级隔离保证。
- 可选网络评测依赖的安全限制见 [安全说明](RELEASE_SECURITY_20260927.md)；该依赖不包含在桌面安装包中。
- 未完成全面的真实模型质量与并发性能验证。

## 下载与反馈

安装器及其摘要以 Releases 页面实际附件为准。反馈问题时提供版本、系统信息、复现步骤和脱敏日志，不要提交 API Key、数据库或完整个人学习资料。
