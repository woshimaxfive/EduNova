# 桌面分发安全说明

## 运行与隐私

桌面应用会在本地保存学习数据和配置。外部模型请求按用户选择的服务处理；提交问题反馈前须移除密钥和个人资料。详见 [隐私说明](PRIVACY.md) 和 [安全政策](../SECURITY.md)。

## 可选网络评测依赖

可选 Ragas 0.4.3 涉及 [CVE-2026-6587](https://github.com/advisories/GHSA-95ww-475f-pr4f)。该依赖不包含在桌面安装包中；不要在不可信资料上启用受影响的可选评测功能。启用或升级前应核对适用安全公告。

## 安全边界

桌面权限控制、IPC 来源校验、导航限制和代码策略不能替代操作系统安全更新，也不构成完整的恶意代码隔离保证。

分发方须核对实际随包组件与模型的许可、版权通知和对应源码材料。依赖扫描结果不等于所有传递依赖、模型或原生二进制均无风险。具体版本的已知限制见 [发布说明](RELEASE_NOTES_0.1.0.md)。
