# EduNova 安全设计

本文说明账号、画像、资料与模型凭据的安全边界；漏洞报告见[安全政策](../SECURITY.md)。

## 1. 账号与鉴权

- 密码使用安全哈希保存，不存储明文；
- 业务接口使用 Bearer Access Token；
- 用户只能读取和修改自己的资料、课程、会话和产物；
- 课程访问同时验证 ownership 或 enrollment；
- 权限判断在服务端完成，不依赖前端隐藏按钮。

当前实现使用 Access Token。需要长期公网运行时，应结合部署环境补充短期令牌、刷新令牌、服务端失效和异常登录控制。

## 2. 模型凭据

- `.env` 中的系统凭据不进入 Git；
- 用户 API Key 使用 `MODEL_SETTINGS_ENCRYPTION_KEY` 加密保存；
- 设置接口只返回脱敏状态；
- 日志、Trace、导出和异常响应不能包含明文 Key；
- 用户选择的 Provider 不会在失败后自动切换到未经授权的 Provider。

备份数据库时必须分开保护配置加密密钥。

## 3. 文件上传

上传校验扩展名、MIME、大小、格式和逻辑存储键，不将文件名直接用作服务器路径。

公开部署建议启用 ClamAV，并对压缩包、图片尺寸、文档解析时间和对象存储权限设置限制。上传文件与应用源码、静态资源和执行目录分离。

Docker 代码验证使用独立服务、非 root、只读文件系统、资源限制与超时，只处理受支持的 Python 片段。桌面执行隔离边界见[桌面 README](../desktop/README.md)。

## 4. 用户与课程隔离

数据库、检索、缓存、任务和文件访问都必须携带用户范围。课程级画像、弱点、路径、练习、报告和资源反馈进一步按课程隔离。

检索候选、向量查询、对象键和任务输入均须在源头限定范围，不能只过滤最终响应。

## 5. Agent 与工具

模型输出不直接获得数据库、文件或网络权限。工具调用执行前验证权限、参数、课程范围、预算和取消状态，执行后验证并脱敏结果。

客观评分、引用合法性、掌握度和正式学习状态由确定性代码控制。网页内容和未确认模型结论不能直接成为正式学习证据。

## 6. 日志与可观测性

- 允许：trace/job 标识、工作流与安全步骤、耗时、状态、错误码、Provider/模型名称、引用/工具数量及脱敏质量结果。
- 禁止：密码、JWT、完整 API Key、系统提示词、原始推理、用户资料/作答/上传原文、Provider 原始响应及宿主机绝对路径。

## 7. 存储

本地存储适合开发和单机试用。公网部署应优先使用隔离的 S3-compatible bucket、最小权限凭据、服务端加密和生命周期规则。

公开下载必须经过权限校验或短期签名 URL，不能直接暴露内部对象键和宿主机路径。

## 8. 网络与部署

- 对外只公开 HTTPS Nginx 入口；
- PostgreSQL、Redis、Backend、Worker 和代码验证服务使用内部网络；
- 生产环境关闭调试模式；
- 限制请求体、上传大小、并发、超时和重试；
- 外部 Provider 使用 HTTPS/WSS；
- 定期更新依赖和基础镜像。

## 9. 隐私控制

暂停记忆会停止读取与后台写入，保留已有内容和索引。清除索引与永久删除内容分别执行，均保留原始会话。

完整说明见[隐私说明](PRIVACY.md)。

## 10. 发布检查

公开发布前至少确认：

- `.env`、凭据、上传资料、数据库、日志和导出文件未被跟踪；
- Gitleaks 或等效工具扫描当前树和 Git 历史；
- 依赖许可证与漏洞检查已运行；
- Docker Compose 配置可解析；
- 上传、鉴权、用户隔离和对象存储边界已验证；
- 文档没有真实账号、个人路径或私有资料；
- 未运行的安全检查明确标记为未验证。
