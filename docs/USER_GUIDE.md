# EduNova 用户指南

更新时间：2026-07-05

## 1. 快速开始

打开系统后，可以选择：

- 注册新账号并空白开始。
- 注册新账号并选择“带一个示例课程开始”。

当前快速体验推荐选择示例课程。系统会把“人工智能导论”复制到当前用户空间，后续学习记录只属于当前账号。

## 2. 首页

登录后进入 `/app`。

首页可以：

- 查看最近课程。
- 查看资料库摘要。
- 进行 AI 问答，可按需开启联网搜索、深度回答，并选择资料作为本次对话参考。
- 使用浏览器语音输入学习问题，或朗读回答。
- 进入资料库、课程空间、资源工坊、学习路径、练习和报告。

首页普通问答不做课程 RAG；选择资料后会使用资料短摘录作为参考，开启联网搜索后需要系统配置搜索 Key。需要基于课程知识库和引用回答时，请进入对应课程空间。

## 3. 资料库

进入 `/app/library`。

支持：

- 上传资料。
- 查看资料列表和解析状态。
- 搜索和筛选资料。
- 从已解析 TXT/Markdown/PDF/DOCX/PPTX 资料生成课程。
- 选择同一课程下两份以上资料做资料对比。

当前限制：

- TXT/Markdown/PDF/DOCX/PPTX 可用于规则建课。
- 旧版 DOC/PPT 只入库，不做深度解析。
- 图片和扫描件只入库，不做 OCR。

## 4. 课程空间

进入 `/app/courses/{course_id}`。

课程空间默认是问答模式：

- 输入课程问题。
- 查看基于课程资料的引用。
- 查看回答下方的来源、学习路径、生成资源和思考过程。
- 对待复习弱点执行确认、开始、完成或忽略。

点击知识点或引用来源可以进入学习模式，围绕当前知识点继续提问。

## 5. 学习画像

进入 `/app/profile`。

可以：

- 查看 8 维用户级学习画像。
- 通过画像对话更新目标、基础、偏好和节奏。
- 查看画像事件。

画像是用户级长期信息，不会为每门课程复制一份。课程差异在课程学习状态、弱点、路径和掌握度中体现。

## 6. 资源工坊

进入 `/app/studio`。

可以选择课程、知识点和资源类型，生成：

- 讲解文档。
- 思维导图。
- 练习题。
- 代码案例。
- PPT 大纲。

资源会显示生成模式：

- 模型增强。
- 本地可用稿。
- 低依据。

低依据表示课程资料不足，不等于系统失败。

## 7. 学习路径和期末冲刺

进入 `/app/path`。

普通学习路径：

- 选择课程。
- 生成 3/7/14 天学习路径。
- 更新任务状态。
- 查看掌握度图和推荐资源。

期末冲刺：

- 选择 3/7/14 天。
- 生成每日任务、高频点、薄弱点、必刷题和易错提醒。

## 8. 练习

进入 `/app/practice`。

可以：

- 选择课程和知识点。
- 设置题量和难度。
- 创建练习。
- 作答并提交。
- 查看即时反馈。

错题或低分题会进入课程级弱点队列，并影响掌握度。

## 9. 报告和导出

进入 `/app/reports`。

可以：

- 选择课程。
- 读取最新报告。
- 生成新报告。
- 查看分数、掌握度、弱点、证据摘要和下一步建议。
- 导出 Markdown 学习档案。

当前只支持 Markdown 导出，不支持 PDF/Word。

## 10. 设置

进入 `/app/settings`。

可以管理多套模型配置：

- 新建 OpenAI-compatible 配置。
- 测试连接。
- 设置默认配置。
- 删除配置。

用户 API Key 会加密保存，界面只显示脱敏信息。
