# EduNova 用户指南

## 1. 快速开始

打开系统后，可以选择：

- 注册新账号并空白开始。
- 注册新账号并选择“从数据结构与算法开始”。

新账号默认空白开始。主动选择内置课程后，系统会把“数据结构与算法”复制到当前用户空间，后续学习记录只属于当前账号。内置章节与实验是课程内部来源，不会出现在个人资料库。

## 2. 首页

登录后进入 `/app`。

首页可以：

- 查看最近课程。
- 查看资料库摘要。
- 进行 AI 问答；联网核实和推理强度由系统按问题自动判断，也可选择资料作为本次对话参考。
- 使用浏览器语音输入学习问题，或朗读回答。
- 进入资料库、课程空间、资源工坊、学习路径、练习和报告。

首页普通问答不做课程 RAG；选择资料后会使用受限资料短摘录作为参考。需要联网时系统优先使用当前 Provider 已验证的原生搜索能力，否则使用已配置的外部搜索服务；两者都不可用时会明确降级。需要基于课程知识库和教材引用回答时，请进入对应课程空间。

## 3. 资料库

进入 `/app/library`。

支持：

- 上传资料。
- 查看资料列表和解析状态。
- 搜索和筛选资料。
- 检查 TXT/Markdown/PDF/DOCX/PPTX 的目录、页码和真实切片。
- 确认资料结构后生成课程。
- 选择同一课程下两份以上资料做资料对比。

资料库只展示用户上传的原文件。目录候选、切片、页码和解析诊断只保存在系统内部，不会复制成额外的个人资料条目。

上传后系统会在后台精细解析。状态变为“待确认”时，打开资料详情依次检查：

1. 概览中的页数、章节数、切片数、质量和 warning。
2. 目录中的章节层级、页码范围和包含状态；可排除封面、目录或附录，也可改名、合并或拆分错误边界。
3. 切片中的真实正文、章节路径和页码。
4. 确认目录。只有已确认且质量通过的资料才能用于问答、对比和建课。

旧资料会显示为 `legacy`，需要用户主动重新解析；系统不会在升级时自动消耗模型或向量额度。

当前限制：

- 已确认且质量通过的 TXT/Markdown/PDF/DOCX/PPTX 可用于智能建课。
- 旧版 DOC/PPT 只入库，不做深度解析。
- 图片和扫描件只入库，不做 OCR。

## 4. 课程空间

进入 `/app/courses/{course_id}`。

课程空间默认是问答模式：

- 输入课程问题。
- 查看基于课程资料的引用。
- 查看回答前的“协作完成”状态行，展开可回看本轮安全阶段与用时；回答下方可查看来源、下一步学习、生成资源和为什么这样回答。系统不展示模型原始思维链。
- 对待复习弱点执行确认、开始、完成或忽略。

点击知识点或引用来源可以进入学习模式，围绕当前知识点继续提问。

## 5. 学习画像

进入 `/app/profile`。

可以：

- 查看 8 维用户级学习画像。
- 通过画像对话更新目标、基础、偏好和节奏。
- 查看画像事件。

画像是用户级长期信息，不会为每门课程复制一份。课程差异在课程学习状态、弱点、路径和掌握度中体现。

## 6. 资源工坊

进入 `/app/studio`。

可以选择课程、知识点和资源类型，生成：

- 讲解文档。
- 思维导图。
- 练习题。
- 代码案例。
- PPT 页面与可下载 PPTX。
- 可播放的动画图解。

资源会显示生成模式：

- 模型增强。
- 本地可用稿。
- 低依据。

低依据表示课程资料不足，不等于系统失败。

每份新资源会显示“为什么为你这样生成”，说明当前学习问题、采用的教法和它与其他资源的分工。系统不会展示完整画像或原始作答。

对已有成果点击“重新生成”时可以选择：

- **换一种教法**：保留目标和资料依据，改变教学策略、案例或学习活动。
- **优化当前版本**：保留原教学意图，修正事实、结构、表达和交互质量。

旧版本不会被覆盖。成果库按版本族展示最新版本，可以在成果顶部切换版本或打开版本比较，随时回到旧版本。

## 7. 学习路径

进入 `/app/path`。

- 选择课程。
- 点击“一键生成学习路径”，系统直接给出有序学习任务，不设置日期或期限。
- 更新任务状态。
- 查看掌握度图和推荐资源。没有练习或弱点证据的知识点显示“未评估”，不会因为加入路径就自动获得分数。
- 完成练习后，已有路径会保留完成进度并把新弱点提前。

资料对比位于资料库，用于独立查看共同重点、差异遗漏和复习优先级，不会自动修改学习路径。

## 8. 练习

进入 `/app/practice`。

可以：

- 选择课程和知识点。
- 设置题量和难度。
- 创建练习。
- 作答并提交。
- 查看即时反馈、错因、缺失概念和建议复习动作。

新练习基于课程引用生成不同题面。选择题提交后会显示正确答案和解析；系统生成的代码资源只有实际运行结果与预期一致后才会出现在资源工坊。

错题或低分题会进入课程级弱点队列，并影响掌握度。若该课程已有普通学习路径，系统会保留已完成任务并把新确认弱点排到前部；从未建立路径时不会擅自创建默认路径。“查看 AssessmentGraph”和“查看 PathPlanningGraph”只展示安全节点摘要，不展示原始思维链。

## 9. 报告和导出

进入 `/app/reports`。

可以：

- 选择课程。
- 读取最新报告。
- 生成新报告。
- 查看分数、掌握度、最近练习趋势、弱点、证据摘要和下一步建议。
- 展开真实 `ReportGraph` 协作轨迹。
- 异步导出 Markdown、PDF 或 DOCX 学习档案。

报告需要主动点击生成，不会在每次提交练习时自动调用模型。报告会分别展示练习次数、已作答题数、正确题数、已评估知识点数和已完成路径任务数；这些数字由规则计算并锁定，模型只增强总结和建议。

## 10. 设置

进入 `/app/settings`。

可以管理多套模型配置：

- 在同一套配置中分别填写回答、向量和重排序服务；三者可以来自不同服务商，分别使用自己的地址、凭证和模型。
- 新配置默认推荐讯飞 Spark X2-Flash 回答、讯飞 LLM Embedding 和硅基 BGE Reranker。只有填写并保存完整凭证的能力才会启用，额度以服务商控制台为准。
- 讯飞向量需要 APPID、APIKey、APISecret；百炼和硅基向量使用各自 API Key。向量维度由预设或连接测试识别，不需要手填。
- 暂时没有向量 API 时选择“暂不配置”，系统继续使用关键词检索，不影响普通回答功能。
- 重排序用于把关键词和向量召回的候选再次精排；未配置时仍可使用 RRF 混合排序。
- 分别测试并设置回答、向量和重排序默认；三种用途可来自同一套组合配置，也可选择不同配置。
- 更换默认向量后，如需让既有资料使用新配置，主动点击“重建向量索引”；仅切换配置不会自动消耗额度。
- 删除配置。

回答模型负责对话和内容生成，向量模型负责语义召回，重排序模型负责候选精排。未配置后两项不会影响正常对话。

用户 API Key 会加密保存，界面只显示脱敏信息。

## 11. 下一步学习

首页、资料库、课程空间、路径、资源工坊、练习结果、报告和画像会显示同一套“下一步学习”。系统会优先恢复正在进行的资料解析、课程生成或路径任务；如果刚上传的新资料晚于最近课程活动，会先引导完成目录确认和建课。

行动条只推荐一个主要动作，不会自动上传、确认目录、生成课程或路径、提交练习、生成报告，也不会自动完成后续路径任务。从路径进入资源时会保留任务上下文，完成资源学习后可明确标记该任务完成并返回下一步。后台任务完成后，任务托盘提供“查看结果”。
