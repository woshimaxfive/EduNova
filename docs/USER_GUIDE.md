# EduNova 用户指南

更新时间：2026-07-05

## 1. 快速开始

打开系统后，可以选择：

- 注册新账号并空白开始。
- 注册新账号并选择“带一个示例课程开始”。

当前快速体验推荐选择示例课程。系统会把“人工智能导论”复制到当前用户空间，后续学习记录只属于当前账号。

## 2. 首页

登录后进入 `/app`。

首页可以：

- 查看最近课程。
- 查看资料库摘要。
- 进行 AI 问答，可按需开启联网搜索、深度回答，并选择资料作为本次对话参考。
- 使用浏览器语音输入学习问题，或朗读回答。
- 进入资料库、课程空间、资源工坊、学习路径、练习和报告。

首页普通问答不做课程 RAG；选择资料后会使用资料短摘录作为参考，开启联网搜索后需要系统配置搜索 Key。需要基于课程知识库和引用回答时，请进入对应课程空间。

## 3. 资料库

进入 `/app/library`。

支持：

- 上传资料。
- 查看资料列表和解析状态。
- 搜索和筛选资料。
- 从已解析 TXT/Markdown/PDF/DOCX/PPTX 资料生成课程。
- 选择同一课程下两份以上资料做资料对比。

当前限制：

- TXT/Markdown/PDF/DOCX/PPTX 可用于规则建课。
- 旧版 DOC/PPT 只入库，不做深度解析。
- 图片和扫描件只入库，不做 OCR。

## 4. 课程空间

进入 `/app/courses/{course_id}`。

课程空间默认是问答模式：

- 输入课程问题。
- 查看基于课程资料的引用。
- 查看回答下方的来源、学习路径、生成资源和思考过程。
- 对待复习弱点执行确认、开始、完成或忽略。

点击知识点或引用来源可以进入学习模式，围绕当前知识点继续提问。

## 5. 学习画像

进入 `/app/profile`。

可以：

- 查看 8 维用户级学习画像。
- 通过画像对话更新目标、基础、偏好和节奏。
- 查看画像事件。

画像是用户级长期信息，不会为每门课程复制一份。课程差异在课程学习状态、弱点、路径和掌握度中体现。

## 6. 资源工坊

进入 `/app/studio`。

可以选择课程、知识点和资源类型，生成：

- 讲解文档。
- 思维导图。
- 练习题。
- 代码案例。
- PPT 页面与可下载 PPTX。
- 可播放的动画图解。

资源会显示生成模式：

- 模型增强。
- 本地可用稿。
- 低依据。

低依据表示课程资料不足，不等于系统失败。

## 7. 学习路径

进入 `/app/path`。

- 选择课程。
- 点击“一键生成学习路径”，系统直接给出有序学习任务，不设置日期或期限。
- 更新任务状态。
- 查看掌握度图和推荐资源。没有练习或弱点证据的知识点显示“未评估”，不会因为加入路径就自动获得分数。
- 完成练习后，已有路径会保留完成进度并把新弱点提前。

资料对比位于资料库，用于独立查看共同重点、差异遗漏和复习优先级，不会自动修改学习路径。

## 8. 练习

进入 `/app/practice`。

可以：

- 选择课程和知识点。
- 设置题量和难度。
- 创建练习。
- 作答并提交。
- 查看即时反馈、错因、缺失概念和建议复习动作。

新练习基于课程引用生成不同题面。选择题提交后会显示正确答案和解析；系统生成的代码资源只有实际运行结果与预期一致后才会出现在资源工坊。

错题或低分题会进入课程级弱点队列，并影响掌握度。若该课程已有普通学习路径，系统会保留已完成任务并把新确认弱点排到前部；从未建立路径时不会擅自创建默认路径。“查看 AssessmentGraph”和“查看 PathPlanningGraph”只展示安全节点摘要，不展示原始思维链。

## 9. 报告和导出

进入 `/app/reports`。

可以：

- 选择课程。
- 读取最新报告。
- 生成新报告。
- 查看分数、掌握度、最近练习趋势、弱点、证据摘要和下一步建议。
- 展开真实 `ReportGraph` 协作轨迹。
- 异步导出 Markdown、PDF 或 DOCX 学习档案。

报告需要主动点击生成，不会在每次提交练习时自动调用模型。报告会分别展示练习次数、已作答题数、正确题数、已评估知识点数和已完成路径任务数；这些数字由规则计算并锁定，模型只增强总结和建议。

## 10. 设置

进入 `/app/settings`。

可以管理多套模型配置：

- 在同一套配置中分别填写回答、向量和重排序服务；三者可以来自不同服务商，分别使用自己的地址、凭证和模型。
- 新配置默认推荐讯飞 Spark X2-Flash 回答、讯飞 LLM Embedding 和硅基 BGE Reranker。只有填写并保存完整凭证的能力才会启用，额度以服务商控制台为准。
- 讯飞向量需要 APPID、APIKey、APISecret；百炼和硅基向量使用各自 API Key。向量维度由预设或连接测试识别，不需要手填。
- 暂时没有向量 API 时选择“暂不配置”，系统继续使用关键词检索，不影响普通回答功能。
- 重排序用于把关键词和向量召回的候选再次精排；未配置时仍可使用 RRF 混合排序。
- 分别测试并设置回答、向量和重排序默认；三种用途可来自同一套组合配置，也可选择不同配置。
- 更换默认向量后，如需让既有资料使用新配置，主动点击“重建向量索引”；仅切换配置不会自动消耗额度。
- 删除配置。

回答模型负责对话和内容生成，向量模型负责语义召回，重排序模型负责候选精排。未配置后两项不会影响正常对话。

用户 API Key 会加密保存，界面只显示脱敏信息。
