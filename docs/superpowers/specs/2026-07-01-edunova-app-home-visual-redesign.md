# EduNova `/app` 首页视觉重建规格

日期：2026-07-01

## 1. 目标

本次只重建 `/app` 第一眼，不扩大后端范围，不进入真实 AI/RAG。目标是把上一版“功能结构验证页”改成更像成熟 AI 学习产品的首页：对话是主角，资料库和课程入口保持轻量，页面不能像后台管理系统或卡片墙。

## 2. 参考原则

- 参考 ChatGPT：贴边可收起侧栏、中心输入、发送后下方输入区、历史连续性、工具弱化、回答后的引用和过程展开。
- 参考 OpenMAIC：首页上方是亲和的学习入口，下方才露出最近课程或课程发现。
- 保留 EduNova 自己的方向：学生上传资料、生成课程、进入课程空间学习。

## 3. 首屏结构

```text
贴边可收起侧栏      中心 AI 学习入口
EduNova / 导航       嗨，同学，准备好一起学习了吗？
新建对话            上传课件、电子书或期末题，然后直接问
搜索历史            轻量输入框
今天/本周历史        上传资料 / 打开资料库 / 生成课程 / 联网搜索 / 深度思考 / 语音

                    最近学习轻量列表
                    人工智能导论 / 期末冲刺课 / Python 基础补齐

发送后              主页对话流
                    下方固定输入区
```

桌面端保留贴左边缘侧栏，中心区域拥有最大视觉权重。资料库不再作为右侧大栏，而是通过输入区按钮打开浮层。移动端先显示中心输入，再显示最近学习，历史对话降级为下方列表。

## 4. 视觉规则

- 页面使用安静浅色，避免大面积紫蓝 AI 渐变。
- 背景只允许轻微纸面纹理和缓慢光带，不使用离散装饰球。
- 卡片数量减少：输入框是主要容器，最近课程使用轻量列表和细分隔线，不做大卡片墙。
- 首页允许一层克制的 `learning-signal` 线性微动效，用来形成 EduNova 的记忆点；动效必须支持 reduced motion，不能干扰阅读。
- 按钮以图标和短文字为主，工具弱化在输入框底部。
- 首屏文案短，避免解释功能清单。

## 5. 验收

- Vitest 覆盖新标题、历史对话、AI 学习入口、语义化最近学习列表、资料库按钮和生成课程浮层。
- 首页不再渲染 `资料库轻入口` 右侧区域，也不渲染 `知识学习画布`。
- 浏览器检查桌面和移动端无水平溢出，中心输入区第一眼占主导。

## 6. P3R3 精修记录

- 标题拆分为两行，降低字重和字号，保留亲和感但减少“海报感”。
- 顶部轻导航、输入框、资料库浮层和生成课程浮层统一收紧圆角、阴影和间距。
- 最近学习从卡片式按钮调整为 `aria-label="最近学习列表"` 的语义化列表，视觉上更像轻量入口。
- 已用本地浏览器检查桌面和移动宽度，未发现水平溢出。
- 根据 ChatGPT 截图补充贴边侧栏、侧栏收起、较小输入框和发送后下方输入区。
