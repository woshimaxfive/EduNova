# EduNova Phase 13 前端视觉硬化规格

日期：2026-07-10

## 1. 目标

在不改变业务能力、路由职责、API 合同和数据结构的前提下，提升现有学生端前端的视觉一致性、移动导航体验、键盘可访问性和课程首屏层级。

本轮属于 Phase 13 Verification and Hardening / 产品打磨，不进入新的功能阶段。

## 2. 范围

### 2.1 设计系统

- 补齐现有 CSS 中已引用但缺失的语义 token。
- 统一品牌色、文字、边框、阴影、圆角和焦点表达。
- 路径蓝只用于路径语义，主品牌和交互使用玉绿色。
- 不引入新的 CSS 框架或组件库。

### 2.2 工作区壳

- 桌面端保留现有贴边侧栏与收起能力。
- `900px` 及以下默认显示紧凑顶部导航条。
- 展开后复用现有 `AppSidebar` 作为覆盖式抽屉，保留完整导航、历史和账号功能。
- 首页、普通路由和课程空间共用响应式侧栏状态逻辑。

### 2.3 页面

- 登录页：修正标题换行、表单层级和品牌色。
- 学习主页：降低模板化大标题与 pill 感，保留 composer 作为第一视觉焦点。
- 资料库：统一标题和主体内容网格。
- 课程空间：重排返回入口、课程摘要、指标和 A3 步骤轨，不改变默认问答与按需学习模式。

## 3. 不做事项

- 不新增教师端、家长端、支付、运营后台或移动 App。
- 不新增 OCR、旧版 Office、扫描件解析或多模态生成能力。
- 不修改 API、数据库、权限、模型配置或 Agent 工作流。
- 不用假课程、假历史、假引用或假状态填充视觉。
- 不恢复横向 `ActionNotice`，不把 `pending` 弱点包装为已诊断。
- 不以更多渐变、光球、粒子或卡片墙掩盖信息层级问题。

## 4. 验收

- 前端 lint、全部 Vitest、TypeScript 和 production build 通过。
- UTF-8 无 BOM 编码检查通过。
- `agent-browser` 覆盖 1440×1000 和 390×844。
- 登录页标题、主页 composer、课程首屏、移动紧凑顶栏和覆盖式抽屉均可见。
- 移动端无水平溢出，抽屉导航动作完成后自动收起。
- Tab 焦点可见，composer 聚焦时容器有明确焦点环。
- 相关状态、看板、UI/UX、路由和测试文档同步。
