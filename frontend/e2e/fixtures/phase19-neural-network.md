# 神经网络前向与反向传播

## 前向传播

单个神经元可计算 `z=w*x+b`，再通过激活函数得到输出。以线性输出为例，当 `x=2`、`w=3`、`b=1` 时，前向传播得到 `z=7`。

## 损失与反向传播

平方损失可写为 `L=(z-y)^2`。反向传播利用链式法则，从损失函数向前逐层计算梯度。若 `y=5`，则 `dL/dz=2*(z-y)=4`，并有 `dL/dw=(dL/dz)*x=8`。

## 参数更新

梯度下降使用 `w_new=w-learning_rate*dL/dw` 更新参数。学习率过大会造成震荡甚至发散，过小则收敛缓慢。代码实操应输出前向结果、损失和梯度，且运行结果必须与预期值一致。
